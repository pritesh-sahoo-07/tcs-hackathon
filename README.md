# 🍽️ TCS Canteen AI

An AI-powered food recommendation web application developed during a **90-minute TCS Hackathon**.

The application helps users discover suitable food items based on their preferences and available canteen menu items.

---

## 🚀 Project Overview

TCS Canteen AI is a Django-based web application designed to make canteen food selection easier and smarter.

Instead of manually searching through a menu, users can interact with the application and receive food recommendations based on available menu data.

### 🎯 Problem

In a busy canteen environment:

- Users may spend time deciding what to eat.
- Large menus can make food selection difficult.
- Users may have different food preferences.
- Finding suitable food quickly can be inconvenient.

### 💡 Solution

We developed a simple AI-assisted canteen recommendation system that:

- Displays available food items.
- Stores food information in a database.
- Allows users to explore menu items.
- Provides food recommendations.
- Uses Django for backend processing.
- Provides a clean and user-friendly web interface.

Development Focus

During the limited development time, the team focused on:

1. Building a working Django backend.
2. Creating the food/menu data model.
3. Implementing recommendation functionality.
4. Connecting the database.
5. Creating a functional frontend.
6. Integrating the complete application flow.
7. Making the application ready for demonstration.

The project demonstrates rapid prototyping, problem-solving, backend development, database integration, and AI-assisted recommendation concepts under strict time constraints.
